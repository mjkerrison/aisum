What's an Unconference?

Much like a normal conference, except the agenda isn't set in advance. Attendees pitch the sessions they want to run (or want someone else to run), everyone votes, and the organisers build the program on the day. Come for the community and the flexibility, not for specific talks!

Applications for AISUM26 will open later in 2026. Places are limited, so we run an application process rather than first-come-first-served. Tickets are priced to partly recoup venue and catering costs, with options to pay less if you need the support.
